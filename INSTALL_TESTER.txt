Site to Figma — расширение Chrome, версия VERSION

Установка
1. Распакуйте архив в любую постоянную папку (не удаляйте её после установки — Chrome берёт расширение оттуда).
2. Откройте в Chrome адрес chrome://extensions
3. Справа сверху включите «Режим разработчика».
4. Нажмите «Загрузить распакованное расширение» и выберите папку extension из архива.
5. Закрепите иконку: значок пазла на панели браузера → булавка у Site to Figma.

Использование
Вкладка «В Figma»:
- Откройте страницу и нажмите иконку расширения — справа сверху появится панель.
- Ширина макета = ширина окна браузера (для мобильной версии сузьте окно или включите режим устройства в DevTools).
- Нужны отдельные блоки? «Выбрать блок на странице» → клик по блоку; Ctrl+клик или Shift+клик добавляет ещё, затем кнопка «Завершить выбор» внизу страницы; ↑ — уровень выше, клик по хлебным крошкам — родитель, Esc — отмена → «Захватить выбранные блоки».
- «Захватить всю страницу» — макет сразу копируется в буфер обмена (уведомление внизу), вставьте его в Figma через Ctrl+V. Или «Скачать .fig» и перетащите файл в Figma.
- Во время захвата виден прогресс и кнопка «Остановить». В «Дополнительных настройках» можно включить «Без auto layout», исключить блоки по селекторам, включить логирование, «Доп. информацию» (размеры, отступы, шрифты рядом с макетом) или несколько ширин из медиа-запросов CSS (кнопка «Найти») либо своя ширина в одном файле. Настройки запоминаются.
- Горячие клавиши: Alt+Shift+C — захватить, Alt+Shift+X — выбрать блок.
- Если что-то не перенеслось, внизу результата откройте «Ошибки при конвертации».
- Иконочные шрифты (Font Awesome, Linearicons и т.п.) переносятся картинками — в Figma этих шрифтов нет.
- При захвате нескольких ширин закройте DevTools на вкладке: на время захвата Chrome показывает индикатор отладки.
- Сложные SVG (анимации, градиенты, тени) приходят картинками «SVG: имя файла». Чтобы заменить на векторы: выделите слой в Figma, в панели нажмите «Копировать» у этого SVG, в Figma — Ctrl+Shift+R.

Вкладка «Медиа»:
- «Найти медиа на странице» → выберите типы (картинки, SVG, видео) → «Скачать выбранное».
- Файлы сохраняются в Загрузки/Site to Figma/<сайт> <дата>/.

Вкладка «Шрифты»:
- «Найти шрифты на странице» → проверьте список → «Скачать выбранное».
- Шрифты (woff2/woff/ttf/otf) сохраняются в Загрузки/Site to Figma/<сайт> <дата>/fonts.
- Если в настройках Chrome включено «Всегда указывать место для скачивания», Chrome спросит место для каждого файла — лучше выключить.

Обновление на новую версию
Замените содержимое папки extension новым и нажмите «Обновить» (круглая стрелка) у расширения в chrome://extensions, затем перезагрузите вкладку с сайтом.

Что присылать при ошибке
Адрес страницы, ширину окна, скриншот сайта и скриншот результата в Figma, текст статуса из панели.
