# Site to Figma

Конвертирует страницу сайта в редактируемые слои Figma: файл `.fig` или вставка через буфер обмена (Ctrl+V). Без ИИ, без аккаунтов и без лимитов.

Два способа запуска, код захвата у них общий:

- **Расширение Chrome** — конвертирует открытую вкладку прямо из браузера (в том числе страницы за логином).
- **Локальный сервер** — вводишь адрес, страница открывается в Chrome без окна.

## Расширение Chrome

Установка (один раз):

1. Откройте `chrome://extensions` и включите «Режим разработчика» (справа сверху).
2. Нажмите «Загрузить распакованное расширение» и выберите папку `extension/` этого проекта.
3. Закрепите иконку Site to Figma на панели (значок пазла → булавка).

Использование:

1. Откройте нужную страницу. Ширина макета = ширина окна браузера: для мобильной версии сузьте окно или включите режим устройства в DevTools.
2. Нажмите иконку расширения — справа сверху появится панель.
3. Чтобы захватить не всю страницу, а блоки, нажмите «Выбрать блок на странице»: подведите мышь к `section`/`div` и кликните. `Ctrl+клик` или `Shift+клик` добавляет ещё блоки, затем нажмите внизу страницы «Завершить выбор» (или обычный клик по блоку). `↑` поднимает выбор на уровень выше, клик по «хлебным крошкам» сверху выбирает родителя, Esc отменяет. Кнопка «Сбросить» возвращает захват всей страницы.
4. Нажмите «Захватить всю страницу» (или «Захватить выбранные блоки»). Во время захвата идёт прогресс-бар с этапом и кнопкой «Остановить». Страница прокрутится до конца (чтобы подгрузились картинки) и вернётся обратно.
5. После захвата макет автоматически копируется в буфер обмена (появится уведомление) — вставьте его в Figma через Ctrl+V. Если нужно файлом — «Скачать .fig» и перетащите его в Figma (или Import на главной).
6. Если на странице есть сложные SVG (анимированные иллюстрации, градиенты, тени), в панели появится их список. В Figma они лежат картинками (слой «SVG: имя файла»). Чтобы заменить на векторы: выделите такой слой в Figma, в панели нажмите «Копировать» у этого файла, в Figma — Ctrl+Shift+R (вставить с заменой). Figma сама переведёт SVG-код в векторы. Анимацию Figma не поддерживает.

В «Дополнительных настройках» — «Без auto layout», исключение блоков по CSS-селекторам, «Только видимая часть страницы», «Логирование» (журнал этапов и ошибок в панели) и ширины из медиа-запросов CSS (определяются кнопкой «Найти» или автоматически при открытии настроек) либо своя ширина: выбранные ширины захватываются подряд и складываются в один `.fig` рядом друг с другом (окно на время меняет размер, затем возвращается). Настройки, последние селекторы и выбранные блоки сохраняются между открытиями панели.

Горячие клавиши: `Alt+Shift+C` — захватить страницу, `Alt+Shift+X` — выбрать блок.

Если что-то не перенеслось, под результатом появляется «Диагностика»: проблемные элементы, картинки и шрифты с причиной.

Всё, что меняется на странице для захвата (шрифты, стили), откатывается после него.

Вкладка «Медиа» — скачать все медиа страницы:

1. Нажмите «Найти медиа на странице» (страница прокрутится, чтобы подгрузились отложенные картинки).
2. Галочками выберите типы (картинки, SVG, видео) и при необходимости снимите отдельные файлы в списке с превью.
3. «Скачать выбранное» — файлы сохраняются в `Загрузки/Site to Figma/<домен> <дата>/images|svg|video`.

Ищутся: `<img>` (наибольший вариант из `srcset`), `<picture>`, видео и их обложки, CSS-фоны (включая `::before/::after`), встроенные `<svg>`, картинки внутри SVG, иконки сайта. Потоковое видео (`blob:`) скачать нельзя.

Вкладка «Шрифты» — скачать все шрифты сайта:

1. Нажмите «Найти шрифты на странице».
2. Проверьте список (семейство, начертание, формат, имя файла) и снимите ненужные галочки.
3. «Скачать выбранное» — файлы сохраняются в `Загрузки/Site to Figma/<домен> <дата>/fonts`.

Собираются все файлы из `@font-face`: встроенные стили, подключённые CSS-файлы, кросс-доменные таблицы (Google Fonts) и вложенные `@import`, а также шрифты из `<link rel="preload" as="font">`. Для одного файла с несколькими весами (вариативный шрифт) веса объединяются в названии.

После правок в `src/` пересоберите (`npm run build`) и нажмите «Обновить» у расширения в `chrome://extensions`.

## Локальный сервер

- Из меню приложений: **Site to Figma**, или `./start.sh` — сервер запустится в фоне и откроется http://localhost:4747.
- Остановить: `./stop.sh` (закрывает и фоновый Chrome).
- Захваты сохраняются в `output/` (`.fig` и `.html` с данными для буфера).
- Чтобы захватить только один блок, раскройте «Захватить только один блок» и укажите CSS-селектор (например, `#hero` или `main .card`). Страница рендерится в выбранной ширине окна, а в макет попадает только этот блок.
- «Только видимая часть» ограничивает высоту макета видимой областью — удобно для очень длинных страниц.

Проверка точности типографики (размеры, интервалы, переносы, базовые линии — по каждому текстовому слою):

```bash
node verify.mjs https://example.com 1440
```

Тесты на локальных страницах (целая страница, блок, несколько блоков, видимая часть, слияние ширин):

```bash
npm test
```

## Как устроено

- `src/core/pipeline.js` — весь захват, выполняется внутри страницы:
  - прокрутка, заморозка анимаций;
  - псевдоэлементы `::before`/`::after` (библиотека их не видит) временно превращаются в настоящие элементы с теми же вычисленными стилями: текст, `attr()`, кавычки, `url()`-картинки и декоративные блоки с `content: ""`;
  - шрифты: решает основной (первый) шрифт элемента. Если он есть в Google Fonts — значит, есть и в Figma — он остаётся (метрики берутся из файла самого сайта, если он его отдаёт). Известные фирменные и системные заменяются на похожие (SF Pro → Inter, Proxima Nova → Montserrat, Arial → Arimo… — `SIMILAR` в `src/core/fonts.js`). Все остальные, нераспознанные, — на шрифт по умолчанию Inter. Замена делается прямо на странице до захвата, поэтому переносы строк совпадают. Иконочные шрифты не трогаются;
  - пробелы в текстах сворачиваются так, как их показывает браузер (по `white-space`): переводы строк и отступы из исходного HTML иначе ломали раскладку строк;
  - нормализация типографики: `line-height: normal` → px, трекинг в `%`/`em` → px, `text-align: start/end` → left/right;
  - конвертация библиотекой [@figit/dom-to-figma](https://github.com/figitdesign/web-to-figma) (MIT), пропатченной при сборке (`build.mjs`): многострочный текст переносится по ширине блока, как в браузере; у букв правильные номера символов после переноса строки;
  - иконки из SVG-спрайтов (`<svg><use href="sprite.svg#icon">`) — библиотека не понимает `<use>`, поэтому ссылка заменяется содержимым иконки из спрайта (внешнего файла или встроенного);
  - SVG-картинки (`src/core/svg.js`): простые (иконки: фигуры со сплошной заливкой/обводкой) встраиваются в страницу и переходят в Figma векторами из оригинального файла; сложные (анимация, градиенты, обрезка, фильтры, текст, стили) — картинкой в 2× разрешении, слой «SVG: имя файла», код оригинала копируется из панели для вставки в Figma (Figma сама переведёт его в векторы). Анимацию Figma не поддерживает;
  - `<canvas>` и `<video>` (анимированные WebGL-градиенты и т.п.) снимаются обычным скриншотом текущего состояния (всё остальное на миг скрывается) и вставляются в слой картинкой (`src/core/snapshots.js`);
  - CSS-фоны (`src/core/backgrounds.js`): библиотека понимает только один градиент, поэтому все слои `background-image` (картинки `url()` и градиенты) собираются отдельно — в обрезанный фрейм «Background» под содержимым блока, с учётом `background-size/position/repeat/origin/clip` и скруглений; мелкие повторяющиеся паттерны — одним слоем с заливкой Tile;
  - несколько блоков или ширин конвертируются по очереди и сливаются в один canvas (`mergeMessages` в `src/core/post.js`): GUID-ы и индексы картинок перенумеровываются, фреймы расставляются с отступом 80 px;
  - сетевые ответы кэшируются между захватами (до 200 URL), картинки/шрифты повторяются с паузой при временных ошибках, прокрутка ограничена 30 секундами;
  - захват можно прервать: пайплайн проверяет флаг отмены между этапами и в загрузчиках шрифтов/картинок;
  - постобработка (`src/core/post.js`): порядок слоёв (библиотека нумерует соседей «0»…«10», а Figma сравнивает их как строки), `position: fixed/sticky` → поведение при прокрутке «Fixed»/«Sticky» в Figma, NaN, пустые глифы (неразрывные пробелы, отсутствующие символы), верх текстового слоя по строке CSS, выравнивание строк, авторазмер текстовых слоёв, исправление авто-раскладки (рамка «по содержимому» с растягиваемыми детьми → фиксированный размер, иначе Figma сжимает подписи), уменьшение картинок до 2× размера на странице, сборка `.fig`.
- `.fig` — ZIP с `canvas.fig` (fig-kiwi; сообщение упаковано в zstd-контейнер без сжатия), `meta.json`, `thumbnail.png`, `images/<sha1>`. Формат описан в [openfig-core](https://github.com/OpenFig-org/openfig-core/tree/main/docs).
- Расширение: `extension/background.js` выполняет сетевые запросы страницы (без ограничений CORS), делает скриншот для превью, меняет размер окна для нескольких ширин и сохраняет файлы через `chrome.downloads`; `extension/content.js` — панель (вкладки «В Figma», «Медиа» и «Шрифты»; выбор блоков — `src/extension/picker.js`, поиск медиа — `src/extension/media.js`, поиск шрифтов — `src/extension/fontscan.js`).
- Сервер: `capture.mjs` открывает страницу в Chrome без окна и запускает тот же конвейер (`dist/inject.js`).

## Ограничения

- Сайты с защитой от ботов (Cloudflare challenge) могут не открыться на сервере; в расширении — работают, если открылись в браузере.
- Символы, которых нет в шрифте (например, «→» в Finlandica), остаются пустыми.
- Плейсхолдеры полей ввода смещены влево на внутренний отступ поля.
- `vertical-align` у строчных элементов (например, крупная кавычка, опущенная ниже строки) не учитывается библиотекой — такой элемент встаёт на общую базовую линию.
- Счётчики CSS (`counter()`) в псевдоэлементах не переносятся; маркеры списков (`::marker`) тоже.
- Cookie-баннеры и чаты убираются вручную через поле «Убрать перед захватом» (CSS-селекторы).
- Выбор блока работает в пределах документа: содержимое `<iframe>` и закрытых shadow root не выбирается (они и раньше не попадали в захват).
- Несколько ширин меняют размер окна браузера; если окно развёрнуто на весь экран или ОС ограничивает размер, фактическая ширина может немного отличаться от выбранной. При включённом режиме устройства в DevTools ширина холста задаётся DevTools и не меняется от размера окна — отключите режим устройства или задайте ширину там.

## Обновление библиотеки

```bash
npm update @figit/dom-to-figma && npm run build
```

Если библиотека изменилась так, что патч не применяется, сборка остановится с сообщением об этом.
